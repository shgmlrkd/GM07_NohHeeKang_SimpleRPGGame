# RPG Console Quest

C# 콘솔 기반 턴제 RPG 게임입니다.

플레이어는 직업을 선택하고 몬스터를 사냥하며 성장할 수 있습니다.

# 주요 기능

## 직업 선택
- 전사
- 마법사
- 궁수

플레이어는 원하는 직업을 선택하여 게임을 진행할 수 있습니다.

## 전투 시스템
- 턴제 전투 방식
  - 플레이어 (선)
  - 몬스터   (후)
- 몬스터 등급 시스템
  - 노말
  - 엘리트
  - 보스

각 몬스터는 서로 다른 능력치를 가지고 있습니다.

## 성장 시스템
- 전투를 통해 경험치 획득
- 레벨업 가능
- 레벨업 시 원하는 능력치 강화 가능
  - 체력
  - 마나
  - 공격력
  - 방어력

## 보상 시스템
사냥 성공 시 다음 보상을 획득할 수 있습니다.

- 경험치
- 골드
  
## 상점 시스템
상점에서 다양한 아이템을 구매할 수 있습니다.

- 무기
- 방어구
- 포션

# 개발 환경
- Language: C#
- Platform: Console
